# Machine Learning Algorithms & Projects

Welcome to my Machine Learning repository! This repository serves as a comprehensive collection of my machine learning journey, containing algorithm implementations from scratch, practical projects, and detailed notes on various ML/AI topics.

## 📂 Repository Structure

### Algorithms & Concepts
- **`Decision Trees/`**: Contains Jupyter Notebooks implementing Decision Trees both from scratch and using Scikit-Learn (e.g., `decision_tree_from_scratch.ipynb`, `DT_Car.ipynb`).
- **`Gradient descent/`**: Includes a detailed implementation of the Gradient Descent algorithm from scratch (`Gradient_descent_from_scratch.ipynb`).
- **`Logictic Regression/`**: Focuses on binary classification problems using Logistic Regression (`BinaryClassification.ipynb`).
- **`Random Forest/`**: Implementation and exploration of Random Forest ensemble models.
- **`Scikit-Learn/`**: Contains various supervised and unsupervised learning models built with Scikit-Learn (`1.1_Linear_models.ipynb`).
- **Root Notebooks**:
  - `Gradient Descent.ipynb`
  - `PCA_sample.ipynb` (Principal Component Analysis)
  - `Softmax.ipynb` (Softmax Regression)

### Practical Projects
- **`Projects/`**: Contains end-to-end practical machine learning projects. 
  - **Diabetes Prediction**: A complete pipeline for predicting diabetes using the `diabetes.csv` dataset.

### Resources & Notes
- **`MLNotes/`**: A rich collection of course materials and PDF notes covering advanced topics such as:
  - Deep Learning (PyTorch)
  - Natural Language Processing (NLP)
  - Generative AI & LLMs (LangChain, Langgraph)
  - API Development (FastAPI)

## 🚀 Getting Started

To run the notebooks and experiment with the code in this repository, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository_url>
   cd ML
   ```

2. **Set up a virtual environment (optional but recommended):**
   ```bash
   python -m venv myvenv
   # On Windows:
   myvenv\Scripts\activate
   # On macOS/Linux:
   source myvenv/bin/activate
   ```

3. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
